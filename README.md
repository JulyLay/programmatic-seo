## 🚀 Як встановити

Відкрий Claude Code, новий чат, встав промт:

```
Встанови мені скіл з репозиторію https://github.com/JulyLay/programmatic-seo.git так, щоб він був доступний у будь-якому чаті назавжди:
1. Зклонуй репозиторій у ~/.claude/skills/programmatic-seo (якщо папки ~/.claude/skills немає — створи).
2. Видали з неї папку .git.
3. Перевір, що є файл ~/.claude/skills/programmatic-seo/SKILL.md.
4. Зроби все сам і коротко підтверди, що скіл встановлено.
```

Або командою в терміналі:

```bash
git clone https://github.com/JulyLay/programmatic-seo.git ~/.claude/skills/programmatic-seo && rm -rf ~/.claude/skills/programmatic-seo/.git
```

Далі просто опиши задачу в чаті або виклич `/programmatic-seo`.
